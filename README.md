# Weather App - Previsão do Tempo

Aplicação de previsão do tempo construída com HTML, CSS e JavaScript puro (Vanilla), sem frameworks ou bibliotecas externas. Permite buscar o clima atual de qualquer cidade do mundo, ou visualizar automaticamente o clima da localização do usuário, através de geolocalização.

✨ Funcionalidades
🔍 Busca de clima por nome de cidade
📍 Detecção automática da localização do usuário (via Geolocation API do navegador), exibindo o clima local assim que a página carrega
🌡️ Exibição de temperatura atual, mínima e máxima (em Celsius)
☁️ Descrição textual da condição do tempo, traduzida para português
🖼️ Ícone dinâmico do clima, atualizado automaticamente de acordo com a condição (dia/noite incluído)
💠 Interface com efeito glassmorphism (vidro fosco), com fundo desfocado e transparência
📱 Layout responsivo, com card de largura adaptável

🛠️ Tecnologias utilizadas
HTML5 — estrutura semântica da página
CSS3 — estilização, com Flexbox, gradientes, glassmorphism (backdrop-filter) e responsividade
JavaScript (Vanilla) — lógica de requisições assíncronas (fetch, async/await), manipulação do DOM e Geolocation API
OpenWeatherMap API — fonte dos dados de clima em tempo real

Aprendizados do projeto

Este projeto foi desenvolvido como exercício prático de fundamentos de front-end, sem uso de frameworks, com foco em:

Manipulação do DOM com JavaScript puro
Requisições assíncronas a APIs REST (fetch, async/await, tratamento de resposta em JSON)
Boas práticas de organização de código (funções reutilizáveis, separação de responsabilidades)
Layout responsivo com Flexbox e efeitos visuais modernos em CSS (glassmorphism)
Boas práticas de segurança básica em projetos client-side (uso de .gitignore para não versionar chaves de API)
